## Pre-flight (day before)

  * ☐ Biosafety assessment (AERO-XBN-BIO-001) reviewed
  * ☐ Weather and launch conditions checked
  * ☐ Logger / UV / radiation / GPS calibrated and logged (AERO-XBN-EQP-001)
  * ☐ Batteries charged; logger clocks set to CST
  * ☐ C1, C2, B1, B2 labeled; same water, temperature and feeding confirmed
  * ☐ Chain of custody form started (AERO-XBN-COC-001)



## Pre-flight (launch day)

  * ☐ Pre-launch counts on C1/B1 and C2/B2 at the same time, entered on F2
  * ☐ Video clip of each dish recorded
  * ☐ C dishes sealed and placed in second sealed, padded container
  * ☐ Leak check passed; seal IDs recorded
  * ☐ Logger started and recording; start time (CST): ______
  * ☐ B dishes kept beside the payload until launch, then held in same transport conditions
  * ☐ Payload secured; release approved by flight lead



## Post-flight (recovery)

  * ☐ Recovery time (CST) and location recorded
  * ☐ Payload exterior and containers inspected; leaks? Y / N
  * ☐ Containers kept sealed; custody hand-off logged
  * ☐ Logger stopped; file copied twice

  * ☐ Time to revival observed for C1 and C2
  * ☐ Recovery counts on C and paired B at the same times (F2)
